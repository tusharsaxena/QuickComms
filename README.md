# Ka0s Quick Comms

A World of Warcraft addon for context-aware quick communication: predefined messages, one click away, on a sleek **comms pad** or a ping-wheel-style **comms dial**, showing the right messages for where you are and what you're doing.

> **Status: design spec in review** ([`docs/superpowers/specs/2026-10-11-quickcomms-v1-design.md`](docs/superpowers/specs/2026-10-11-quickcomms-v1-design.md)). The brainstorm is done and the in-game go/no-go test passed. Nothing is built yet. See [`docs/brainstorm/`](docs/brainstorm/) for research, design exploration and a clickable UX mockup ([`docs/brainstorm/mockup/index.html`](docs/brainstorm/mockup/index.html)).
