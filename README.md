# Ka0s Quick Comms

A World of Warcraft addon for context-aware quick communication: predefined messages, one click away, on a sleek **comms pad** or a ping-wheel-style **comms dial**, showing the right messages for where you are and what you're doing.

> **Status: brainstorming.** Nothing is built yet. See [`docs/brainstorm/`](docs/brainstorm/) for research, design exploration and UX mockups.
