## The title-bar pass, per window (rulings 3 and 4)

Quick Comms draws three windows that have title-bar controls of its own. `W.HeaderButtons` was not
adopted. Each control uses the existing surfaces: `Core.MakeCloseButton` with the owner, the facade's
`S.CloseButton` and `LibKa0s-Tooltip-1.0`'s `AttachTitleTip`, which places a tooltip with
`PlaceAttached`. The tooltip seam is `NS.AttachTitleTip` and `NS.CloseTip` in `core/CoreSetup.lua`,
next to `NS.MakeCloseButton`.

| Window | Control | Tooltip | Rest / hover |
|---|---|---|---|
| Preview window (`modules/PreviewWindow.lua`) | close X (`NS.MakeCloseButton`) | "Close", from the library (Core minor 18). No host change | `icon.tint` / `close.hot`, from the library |
| Modal window, template (`settings/ModalWindow.lua`, the callout popup's) | `ClosePanelButton` (`S.CloseButton`) | **new**: `NS.AttachTitleTip(chrome.close, NS.CloseTip)`, which says "Close" | `icon.tint` / `close.hot`, from the library |
| Modal window, fallback (no template) | close X (`NS.MakeCloseButton`) | "Close", from the library | `icon.tint` / `close.hot`, from the library |
| Comms Pad header row (`modules/Pad_Render.lua`) | collapse toggle ("-" / "+") | **new**: "Collapse", or "Expand" while collapsed | **new**: `icon.tint` at rest and `text.link` on hover. It used to rest in the header font's color, gold under Ka0s Default |

The collapse toggle keeps the header's face and size, the header font plus 2 points. Its color now comes
from the skin and not from the Header tab's font color, which is ruling 4's standardization. It never
had a glow, so there is no glow to keep. A pad's drag strip is the library's `W.DragHandle`, and
LibKa0s pins its marks. The dial hub has no title-bar controls.

Tests come first: the new `tests/test_title_bars.lua` (7 cases). Each window checks that every
title-bar control shows a non-empty tooltip in `gtip.title` and hides it on leave. It also checks that
the rest and hover colors resolve to the tokens under Ka0s Default and Obsidian. Before the change, the
template close's tooltip case and both collapse cases were red.
