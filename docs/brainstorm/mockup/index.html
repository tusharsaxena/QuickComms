Ka0s Quick Comms · UX mockup

Predefined callouts, one keypress away, that change with where you are. Pick a situation below: the Comms Dial, the Comms Pad and the settings all follow it. Click a wedge or a button to "send" a callout and watch the chat frame. In situations where Midnight locks chat for addons, sends go through the secure macro path and some channels show a padlock.

Surface 1Comms Dial

Modelled on Blizzard's ping wheel. Hold the key, flick toward a wedge, release to send; release on the centre to cancel. Default mode is Categories: groups on the first ring, callouts in the sub-ring (›). In Arathi Basin the dial opens straight on the node ring; the centre button goes back to all groups.

Surface 2Comms Pad

Chips instead of buttons: an icon tile, a short label and a channel tag in WoW's own chat colours. The header shows the situation (hover it to see why) and the lockdown state. Pads are unlimited: each one has its own position, layout and group priority.

Why it looks like thisDesign notes

4 wedges by default, 8 max per ring

Marking-menu studies show errors stay low up to 8 wide by 2 deep, and that the 4 compass directions are fastest. The ping wheel uses 4 for the same reason. Rings with 12 slices are allowed only when they have no sub-rings.

Secure path for group chat

In a key, a boss pull or a PvP match, addons can't send chat. Secure macro buttons still can send to party, raid, RW and instance, so callout text is built before combat. %t and {rt8} are filled in by the game at send time.

Locked, not hidden

A Say or Yell callout in a boss fight shows a padlock instead of disappearing. Positions stay put, so flick muscle memory keeps working.

Channel colours you already know

Tags use WoW's default chat colours: party lavender, raid orange, RW red-orange, whisper pink, say white and yell red. Smart channels show the channel they resolve to right now.

Predefined sets

Built-in groups ship for M+, raid, arena and each battleground, on by default in every new profile. They're read-only templates; Customize makes an editable copy, so addon updates never overwrite your edits.

Why is this showing?

Every active group can explain itself: the pad header tooltip and each group's When tab show which conditions matched the current situation.
